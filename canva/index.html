Project 2 · Redesign guide

Making your redesign in Canva

Canva (free at canva.com) is the quickest option if you've used it before. It's good for adding labels, badges, and text, swapping images, and simple layout changes. Some AI tools mentioned below require Canva Pro.

1. Set up Before and After

  1. Find your Before screenshot's size in pixels (Windows: right-click › Properties › Details; Mac: open in Preview › Tools › Show Inspector).
  2. In Canva: Create a design › Custom size, and enter exactly that width and height in px.
  3. Upload the screenshot (Uploads tab), drag it onto the page, then right-click it › Set image as background so it fills the page exactly.
  4. Click Duplicate page. Page 1 is Before; only edit page 2 (After).

2. Cover or remove something

  1. Elements › Shapes: add a square and drag it over the area to hide.
  2. Click its color tile › + (add a new color) › eyedropper icon, then click the background right next to it.
  3. For photo backgrounds, Magic Eraser (in Edit image) can paint out objects; it may require Pro.

3. Add or change text

  1. Cover old text (step 2), then press T or use the Text tab to add a text box.
  2. Match the font from the font menu (search the name, or pick a close look-alike), and match the color with the eyedropper.
  3. Match the size by eye against nearby text, and align with the snapping guides.

4. Add or replace an image

  1. Upload the new image and drag it in. Resize from a corner so it doesn't stretch; double-click to crop.
  2. To replace an existing photo exactly, draw it at the same position and size: select it and use Position to check width, height, X, and Y.
  3. Background Remover (in Edit image) cuts a product out of its background; it may require Pro.

5. Download

  1. Share › Download, file type PNG, and select only page 2 (or both pages to get Before and After from the same export).
  2. If a size slider appears, leave it at 1× so the file matches the original pixel size.

Final check: the flip test. Flip between your two pages. If anything differs besides your concept (size, crop, price, a shape edge that doesn't quite match), fix it before submitting.
