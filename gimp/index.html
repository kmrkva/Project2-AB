Project 2 · Redesign guide

Making your redesign in GIMP

GIMP is a free, Photoshop-like editor for Windows and Mac (download at gimp.org). It's the best free option for editing the photo itself: removing a logo, cleaning up a background, or blending in a new element. Shortcuts show Windows Ctrl; on a Mac use Cmd.

1. Open and protect the original

  1. File › Open your Before screenshot. Note its size in pixels (shown in the title bar, or Image › Image Properties).
  2. Layer › Duplicate Layer, and click the eye icon to hide the original in the Layers panel. Edit only the copy.
  3. Never use Image › Scale Image or Image › Canvas Size. The After must stay the same size as the Before.

2. Remove something (logo, text, clutter)

  1. Zoom in (+ / -).
  2. Heal tool (H): Ctrl+click a clean nearby area to set the source, then paint over the thing to remove. It blends texture and color.
  3. Clone tool (C) works the same way but copies exactly; better for sharp patterns or edges.
  4. Use a soft brush, short strokes, and re-pick the source often so you don't create repeating patterns.

3. Cover an area with a matching color

  1. Color Picker (O): click the background next to the area. This sets the foreground color.
  2. Rectangle Select (R): drag over the area.
  3. Edit › Fill with FG Color, then Select › None (Shift+Ctrl+A).

4. Add text

  1. Text tool (T): click and type. Set the font, size, and color in Tool Options.
  2. GIMP uses fonts installed on your computer. To match a site's font, install it (or a close Google Fonts look-alike) first, then restart GIMP.
  3. Pick the color with the Color Picker so it matches the existing text exactly.

5. Add or replace an image element

  1. File › Open as Layers to bring in the new image as its own layer.
  2. Scale tool (Shift+S) with the chain icon linked so it doesn't stretch; Move tool (M) to position it.
  3. To cut an object out of a photo, select it with Free Select (F) or Fuzzy Select (U), copy, and Edit › Paste as › New Layer.

6. Export

  1. File › Export As (Shift+Ctrl+E), name it with .png, and export. (Plain "Save" makes a GIMP .xcf file, which is useful for keeping layers but not for submitting.)
  2. Confirm the exported file's pixel size matches your Before.

Final check: the flip test. Open Before and After and flip between them. If anything changed besides your concept (size, crop, a smudge from the heal tool), fix it before submitting.
