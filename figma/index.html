Project 2 · Redesign guide

Making your redesign in Figma

Figma is free in the browser at figma.com and is great for layouts: covering and replacing text, adding badges or labels, swapping images, and rearranging page elements. Shortcuts below show Windows Ctrl / Mac Cmd.

1. Set up Before and After

  1. Create a new Design file and paste your Before screenshot (Ctrl/Cmd+V).
  2. With the image selected, press Ctrl/Cmd+Alt/Option+G to wrap it in a frame. The frame matches the image's size. Name it "Before."
  3. Duplicate the frame (Ctrl/Cmd+D), drag the copy beside the original, and name it "After." Only ever edit the After frame.
  4. Lock the screenshot inside After (Shift+Ctrl/Cmd+L) so you don't nudge it by accident.

2. Cover or remove something

  1. Draw a rectangle (R) over the element you want to hide.
  2. In the right panel, click the fill color, then the eyedropper (or press I), and click the background right next to the element. Now it blends in.
  3. On textured or photo backgrounds, a flat rectangle will show. Use an image editor or AI for those parts instead.

3. Add or change text

  1. Cover the old text (step 2), then press T and click to type.
  2. Match the font in the right panel. Figma includes all Google Fonts; if you don't know the site's font, a tool like WhatTheFont can identify it from a screenshot, or pick a close look-alike.
  3. Match the color with the eyedropper, and match the size by comparing against nearby text.

4. Add or replace an image

  1. Drag the new image in, or use Shift+Ctrl/Cmd+K to place it.
  2. Resize from a corner while holding Shift so it doesn't stretch. To crop, double-click the image and choose Crop.
  3. Make it exactly the same size and position as the image it replaces: copy the W, H, X, and Y numbers from the right panel.

5. Export

  1. Select the After frame. At the bottom of the right panel, under Export, click +, choose PNG at 1x, and export.
  2. Export Before the same way, so both come from the same pipeline.
  3. Check that both files have the same pixel dimensions (Windows: right-click › Properties › Details; Mac: open in Preview › Tools › Show Inspector).

Final check: the flip test. Look at Before and After side by side. If anything differs besides your concept (size, crop, price, a stray pixel of old text), fix it before submitting.
